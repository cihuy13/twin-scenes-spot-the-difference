Twin Scenes — a spot-the-difference game: 3 hand-drawn scenes, 7 fair differences each, two panels side by side, a 3-minute timer, hints, streaks and keyboard play.

## Run it

```sh
python3 -m http.server 8000 --directory game
```

Then open http://localhost:8000 in your browser.
